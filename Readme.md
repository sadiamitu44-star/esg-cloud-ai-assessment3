
### Q1_dialogflow/
ESG Sustainability Support Assistant, built in Dialogflow ES (agent: `esg-sustainability-assist-taoi`). Use case: sustainability and facilities incident reporting.

- Exported agent (zip)
- Screenshots of intents, the routine follow-up intent, welcome and fallback responses, and escalation
- Conversation flow diagram
- Example conversation transcripts

### Q3_triage/
LLM-based triage of ESG-related operational messages.

- `original_prompt.txt`: the starting prompt from the brief
- `revised_prompt.txt`: the improved prompt used as the system instruction in Google AI Studio (Gemini Flash)
- `outputs.json`: JSON results for three test messages (water leak, supplier policy, blocked accessible entrance), including two runs of the water leak message
- Colab notebook (`.ipynb`): Hugging Face zero-shot baseline and an open-source (Qwen) attempt
- `zeroshot_scores.txt`: baseline scores
- Screenshots of the outputs, and the Azure architecture diagram

### Q4_notebooklm/
Evaluation of Google NotebookLM (Gemini Notebook) using an ESG policy briefing scenario.

- `experiment_log.md`: features tested, prompts, outputs and accuracy checks against the sources
- List of the three sources used
- Screenshots of chat answers, mind map, quiz, briefing and audio overview

## Tools used
- Dialogflow ES (Google Cloud)
- Google AI Studio (Gemini Flash)
- Hugging Face Transformers, run in Google Colab
- Google NotebookLM (Gemini Notebook)
